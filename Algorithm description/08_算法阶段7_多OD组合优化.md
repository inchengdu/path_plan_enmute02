# 算法阶段 7：多 OD 组合优化

## 1. 阶段作用

从每个 OD 的冻结候选集合中选择一条路径，使整个稠密道路网络的总重叠尽可能小。该阶段只选择候选，不修改任何候选几何。

## 2. 输入接口

### `CombinationStageInput`

| 字段 | 含义 |
|---|---|
| `candidate_sets` | 冻结候选集合 |
| `precompute` | 道路掩码和候选对重叠矩阵 |
| `search_config` | 迭代预算、停滞预算和 Tabu 参数 |
| `combination_random_stream` | 组合搜索专用随机流 |

## 3. 算法流程

### 3.1 状态与初始解

状态向量为：

\[
\mathbf x=(x_1,\ldots,x_R),
\]

其中 \(x_r\) 是 OD \(r\) 当前选择的候选编号。

初始状态固定选择每个 OD 的基准路径：

\[
\mathbf x^{(0)}=(1,1,\ldots,1).
\]

### 3.2 目标

主要目标为：

\[
A_{\mathrm{dense}}(\mathbf x)
=\sum_{r<s}Q_{r x_r,s x_s}.
\]

重叠相同时，依次比较总物理长度、可选软代价和候选编号向量，使结果确定。

### 3.3 邻域和增量

一步只替换一个 OD 的候选。若 OD \(r\) 从候选 \(k\) 改为 \(k'\)，重叠增量为：

\[
\Delta A=\sum_{s\neq r}
\left(Q_{rk',sx_s}-Q_{rk,sx_s}\right).
\]

不需要重新扫描地图。

### 3.4 Reactive Tabu 搜索

1. 枚举全部单 OD 替换移动。
2. 排除仍在 Tabu 期限内的返回移动。
3. 如果 Tabu 移动能够产生新的全局最好结果，则按 aspiration 允许。
4. 选择完整目标最好的允许移动。
5. 更新当前状态、Tabu 期限、循环记录和停滞计数。
6. 持续维护 best-so-far，而不是只返回最后状态。
7. 达到最大迭代、停滞预算或邻域为空时停止。

## 4. 输出接口

### `CombinationResult`

| 字段 | 含义 |
|---|---|
| `selected_candidate_indices` | 每个 OD 最终选中的候选编号 |
| `initial_objective` | 全基准路径网络目标 |
| `best_objective` | 最好组合目标 |
| `iterations` | 实际迭代次数 |
| `stop_reason` | 最大迭代、停滞或无邻域 |
| `objective_trace` | 必要的目标轨迹 |

### `SelectedDensePaths`

按照 OD 顺序返回选中的只读 `DensePath[]`。

## 5. 基本功能检查

- 输出对每个 OD 恰好选择一个有效候选编号。
- 单 OD 替换的增量与完整重叠重算一致。
- best-so-far 的目标不会随迭代变差。
- 搜索不修改冻结候选。
- 相同配置和种子返回相同选择结果。
