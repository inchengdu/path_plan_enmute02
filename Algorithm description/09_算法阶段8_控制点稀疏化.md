# 算法阶段 8：控制点稀疏化

## 1. 阶段作用

把阶段 7 选中的每条稠密运动基元路径转换为较少控制点构成的折线，同时保留无碰撞、几何近似、转角和转弯间隔约束。该阶段为连续控制点优化提供合法初始网络。

## 2. 输入接口

### `SparsifyStageInput`

| 字段 | 含义 |
|---|---|
| `selected_dense_paths` | 每个 OD 选中的 `DensePath` |
| `grid_map` | 硬障碍地图 |
| `beta_theta` | 最大转角 |
| `beta10` | 真实转弯最小间隔 |
| `beta11` | 初始控制点最小间距偏好 |
| `beta12` | 控制点最大间距 |
| `beta13` | 最大几何近似误差 |
| `overlap_support_rule` | 重叠区域支撑点规则 |

## 3. 算法流程

### 3.1 建立保底控制点序列

初始控制点包括：

- 路径起点；
- 每个运动基元的终点；
- 路径终点。

因为原稠密路径由合法运动基元组成，这个序列是保底可行解。某个点不能删除不是阶段失败，只需保留该点。

### 3.2 安全删点

对内部控制点 \(B\) 及其相邻点 \(A,C\)，尝试用直线 \(AC\) 替代 \(AB\) 和 \(BC\)。只有同时满足以下条件才删除：

1. \(B\) 不是起点或终点；
2. 新线段无硬碰撞且非零；
3. 新线段相对原稠密中心线的最大误差不超过 \(\beta_{13}\)；
4. 受影响真实转弯角不超过 \(\beta_\theta\)；
5. 受影响真实转弯间隔不小于 \(\beta_{10}\)。

删点顺序可由几何误差和转角影响形成稳定优先级。删除后重新评价相邻候选点。

本步骤允许形成长度超过 \(\beta_{12}\) 的长直线，因为后续会在原直线上补点。

### 3.3 插入重叠支撑点

根据当前选中路径之间的重叠区域，为连续优化补充必要支撑点。默认把支撑点插在现有控制线段上，以保持路径几何不变。

### 3.4 插入最大间距点

若相邻控制点距离 \(D_i>\beta_{12}\)，将线段均分成：

\[
n_i=\left\lceil\frac{D_i}{\beta_{12}}\right\rceil
\]

段，并在线段上插入 \(n_i-1\) 个共线点。共线插点不改变转角、碰撞或路径形状。

### 3.5 处理短间距偏好

若相邻控制点距离小于 \(\beta_{11}\)，优先尝试删除非必要的共线点。无法在不改变路径形状或结构支撑的条件下删除时，保留该点并记录 `MIN_SPACING_EXCEPTION`。

\(\beta_{11}\) 不是最终连续路径的硬约束。

## 4. 输出接口

### `SparseControlPaths`

每个 `ControlPath` 包含：

| 字段 | 含义 |
|---|---|
| `od_id` | 所属 OD |
| `points` | 路径顺序控制点 |
| `selected_dense_candidate_id` | 来源候选编号 |
| `segment_ids` | 控制线段编号 |

每个 `ControlPoint` 至少包含稳定 ID、顺序编号、坐标、稠密来源、来源类型、保留原因和是否可移动。

### `SparsifyReport`

包含每条路径删点数量、保留原因、支撑补点数量、间距补点数量和短间距例外。

## 5. 基本功能检查

- 每条稀疏路径起点和终点与原路径一致。
- 所有控制线段无硬碰撞。
- 几何误差不超过 \(\beta_{13}\)。
- 真实转角和转弯间隔满足约束。
- 相邻控制点距离不超过 \(\beta_{12}\)。
- 不可安全删除的点被保留，不导致整个阶段失败。
