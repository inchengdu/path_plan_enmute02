# 路径规划算法实现准备：背景

## 1. 文档目的

本组文档把完整算法规格重新组织为面向代码开发的阶段说明。每个阶段只回答四个问题：

1. 该阶段解决什么问题；
2. 该阶段按什么顺序执行；
3. 该阶段接收什么输入；
4. 该阶段产生什么输出。

文档不包含具体代码，也不展开复杂的审计、断言和测试体系。每个阶段只保留能够确认功能是否实现的基本检查。

## 2. 问题背景

算法在带障碍物的二维栅格地图中，为多个起点—终点对（OD）规划道路网络。目标不仅是让每条路径可达和无碰撞，还要在多条路径之间降低道路重叠、软障碍代价和近距离排斥，并满足车辆转弯能力与控制点间距约束。

算法分成两个层次：

- 稠密路径层：使用离散运动基元和 A* 搜索，为每个 OD 构造多条合法候选路径，再从冻结候选中选择一组网络方案。
- 控制点层：把选中的稠密路径转换成稀疏控制折线，再通过连续坐标局部优化改善网络目标。

最终输出是每个 OD 的连续控制点路径、网络指标、运行配置和必要的过程记录。

## 3. 总体目标

网络真实目标为：

\[
J_{\mathrm{true}}=\alpha_1L+\alpha_2D+\alpha_3A+\alpha_4R.
\]

其中：

- \(L\)：全部路径的控制折线总长度；
- \(D\)：软障碍代价；
- \(A\)：不同 OD 道路之间的重叠面积；
- \(R\)：没有重叠但距离过近时的排斥代价。

当前已经明确 \(L\) 和 \(A\) 的计算语义。\(D\) 的聚合公式和 \(R\) 的距离核仍需在正式实验前确定，但代码结构应通过统一指标接口为它们预留位置。

## 4. 核心对象

| 对象 | 含义 |
|---|---|
| `NormalizedConfig` | 已标准化参数、派生参数和随机种子 |
| `GridMap` | 原始障碍、硬障碍、距离场和软代价场 |
| `PrimitiveLibrary` | 量化后的合法运动基元集合 |
| `ODRecord` | 一个 OD 及其基准最短稠密路径 |
| `CandidateSet` | 一个 OD 的冻结候选路径集合 |
| `CandidatePrecompute` | 候选道路掩码和候选对重叠矩阵 |
| `CombinationResult` | 多 OD 组合优化选中的候选编号 |
| `ControlPath` | 一条由控制点构成的连续折线 |
| `NetworkState` | 全部控制路径、指标缓存、冲突和调度状态 |
| `FinalResult` | 最终路径、指标、验证结果和运行记录 |

## 6. 主数据流

```text
原始配置
  -> NormalizedConfig + RandomStreams
  -> GridMap
  -> PrimitiveLibrary
  -> ODRecord[]
  -> CandidateSet[]
  -> CandidatePrecompute
  -> CombinationResult
  -> sparse ControlPath[]
  -> optimized NetworkState
  -> FinalResult
```

每个阶段只依赖显式输入对象，不依赖未记录的全局变量或共享随机数。

## 7. 开发前仍需确定的内容

以下内容会影响数值结果，但不影响模块和接口的搭建：

- 软障碍场的具体衰减函数；
- 网络软障碍指标 \(D\) 的聚合方式；
- 路径排斥项 \(R\) 的距离核与归一化；
- 重叠支撑控制点的精确数量和位置规则；
- 部分 Tabu、Adaptive Threshold、Age 和 Breakout 更新参数；
- 地图形态生成的具体分布和预算数值。

这些规则应作为配置或策略接口提供，不能隐藏在实现常量中。
