# 算法阶段 5：稠密候选路径生成

## 1. 阶段作用

在每个 OD 的基准路径之外，生成多条长度受控且几何不同的合法稠密路径，为多 OD 组合优化提供可选方案。

## 2. 输入接口

### `CandidateStageInput`

| 字段 | 含义 |
|---|---|
| `od_records` | 阶段 4 输出的 `ODRecord[]` |
| `grid_map` | `GridMap` |
| `primitive_library` | `PrimitiveLibrary` |
| `max_candidates_per_od` | \(\eta_7\)，包含基准路径 |
| `min_area_distance` | 候选最小几何差异 \(\eta_8\) |
| `candidate_random_streams` | 按 OD 和尝试编号派生的随机流 |

## 3. 算法流程

### 3.1 初始化候选集合

对每个 OD：

- 把基准路径 \(P_{r1}\) 放在候选集合第一个位置；
- 保存其几何哈希；
- 连续失败计数设为 0；
- 尝试编号设为 0。

### 3.2 随机化候选 A*

每次尝试创建新的搜索权重、稳定偏置参数和随机种子。候选 A* 仍使用合法运动基元和硬碰撞约束，但搜索优先级可以包含有界、可复现的状态偏置，使搜索产生不同路径。

同一状态在同一次搜索中必须得到相同偏置，不能按节点访问顺序消费共享随机数。

### 3.3 固定接纳顺序

候选路径按以下顺序判断，第一项失败后停止：

1. 搜索是否返回路径；
2. 起点和终点是否正确；
3. 是否在地图内且无硬碰撞；
4. 基元序列和实际转角是否正确；
5. 物理长度是否满足：
   \[
   L(P_{\mathrm{new}})\leq1.2L_r^*;
   \]
6. 稠密坐标是否与已有候选完全重复；
7. 与已有候选的最小归一化面积差异是否大于 \(\eta_8\)。

几何差异使用两条同 OD 路径形成的闭合折线及其绕数面积，可处理路径交叉、回退和自相交。

### 3.4 更新与停止

- 接受：加入候选集合，保存哈希，连续失败计数清零。
- 拒绝：连续失败计数加 1。
- 候选数达到 \(\eta_7\) 时停止。
- 连续 5 次失败时停止。
- 候选不足 \(\eta_7\) 不导致 OD 失败，因为至少保留基准路径。

## 4. 输出接口

### `CandidateSet[]`

| 字段 | 含义 |
|---|---|
| `od_id` | 所属 OD |
| `baseline_path` | 第一个候选 |
| `baseline_length` | \(L_r^*\) |
| `candidates` | 已接受的稠密路径 |
| `hashes` | 候选几何哈希集合 |
| `stop_reason` | 达到数量、连续失败或无需生成 |
| `frozen` | 本阶段结束时仍为 `false` |

### `CandidateAttemptLog[]`

每次尝试记录 OD、尝试编号、搜索参数、种子、搜索状态、拒绝阶段、返回长度和最近几何差异。

## 5. 基本功能检查

- 每个候选集合的第一个元素始终是基准路径。
- 接受的随机候选不超过 1.2 倍基准长度。
- 完全重复的稠密坐标不会重复加入。
- 成功后连续失败计数清零，连续 5 次失败后停止。
- 同一配置和种子生成相同候选与尝试日志。
