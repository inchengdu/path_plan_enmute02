# 算法阶段 1：配置与随机流初始化

## 1. 阶段作用

把用户配置转换成后续模块可以直接使用的标准配置，计算派生参数，并为各阶段创建互不干扰的随机流。

## 2. 输入接口

### `RawConfig`

| 字段组 | 内容 |
|---|---|
| 研究参数 | \(\alpha_1\sim\alpha_4\)、\(\beta_1\sim\beta_{14}\)、\(\beta_\theta\)、\(\eta\) 参数、\(K\) |
| 地图参数 | 机器人半径、障碍形态和生成预算 |
| 搜索参数 | 候选数量、A* 预算、组合搜索参数 |
| 控制优化参数 | 候选分辨率、Tabu、阈值、Breakout、五点恢复重试预算 |
| 随机种子 | 地图、OD、候选、组合、控制优化根种子 |
| 可选兼容字段 | 旧版显式 `beta10`、`beta11` |

## 3. 算法流程

1. 读取配置并检查必需字段是否存在。
2. 检查主要数值是否有限、范围是否合理。
3. 读取 TOML 的角度制字段 `beta_theta_deg`，执行唯一一次角度转换：
   \[
   \beta_\theta
   =\operatorname{radians}(\texttt{beta\_theta\_deg})
   =\texttt{beta\_theta\_deg}\frac{\pi}{180}.
   \]
4. 使用转换后的弧度值计算：
   \[
   \beta_{10}=\lceil1/\beta_\theta\rceil,
   \qquad\beta_{11}=\beta_{10}.
   \]
5. 检查 \(\beta_{10}<\beta_{14}<\beta_{12}\)。
6. 若旧配置包含 `beta10` 或 `beta11`，确认它们与派生值一致。
7. 固定控制点局部规则：五点窗口半径为 2，首点临时角度倍率为 2，随机调度概率为 0.10，严格轮与随机轮交替。
8. 把默认工程参数显式写入标准配置。
9. 从根种子派生地图、OD、候选、组合以及每个控制优化轮的独立随机流键。
10. 生成配置哈希和运行标识。

## 4. 输出接口

### `NormalizedConfig`

| 字段 | 含义 |
|---|---|
| `schema_version` | 配置版本 |
| `research_parameters` | 标准化后的研究参数 |
| `engineering_parameters` | 显式工程参数和预算 |
| `beta_theta_deg` | 只用于配置快照的原始角度制输入 |
| `beta_theta_rad` | 后续全部算法模块使用的弧度值 |
| `beta10` | 从 \(\beta_\theta\) 派生的整数 |
| `beta11` | 等于 `beta10` |
| `schedule_rule` | 严格轮与 10% 随机轮的交替规则 |
| `config_hash` | 标准配置哈希 |

### `RandomStreams`

| 字段 | 含义 |
|---|---|
| `map_key` | 地图生成随机流键 |
| `od_key` | OD 采样随机流键 |
| `candidate_key(od, attempt)` | 指定候选尝试随机流键 |
| `combination_key` | 组合搜索随机流键 |
| `control_key(round)` | 指定控制优化轮随机流键 |

### `RunManifestBase`

包含运行 ID、配置哈希、参数快照和种子清单。

## 5. 基本功能检查

- 能正确派生 \(\beta_{10}\) 和 \(\beta_{11}\)。
- `beta_theta_deg = 10` 能唯一转换为约 `0.1745329252` 弧度，后续阶段不再读取度数字段。
- 明显非法的参数关系会被拒绝。
- 同一原始配置产生相同标准配置哈希和随机流键。
- 各模块随机流互不共用。
