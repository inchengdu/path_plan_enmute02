# 算法阶段 9：连续控制点优化

## 1. 阶段作用

在不改变 OD 起终点的前提下，移动稀疏控制路径的中间点，降低路径长度、软障碍代价、道路重叠和近距离排斥。该阶段采用局部候选网格、Effect Score 调度、Tabu/阈值搜索以及五点局部约束传递。

## 2. 输入接口

### `ControlOptimizationInput`

| 字段 | 含义 |
|---|---|
| `sparse_control_paths` | 阶段 8 输出的合法控制路径 |
| `grid_map` | 硬障碍图和 `obstacle_cost_field` |
| `config` | 目标权重、\(\beta\) 参数、轮数和搜索参数 |
| `metric_provider` | 按统一累计规则计算 \(D\)、\(R\) 及其移动增量的策略接口 |
| `control_random_streams` | 每个优化轮独立随机流 |

## 3. 主要状态接口

### `NetworkState`

| 字段 | 含义 |
|---|---|
| `control_paths` | 当前全部控制路径 |
| `road_masks_by_path` | 每条路径的当前道路掩码 |
| `occupancy_count` | 每个栅格被多少条道路占用 |
| `true_metrics` | 当前 \(L,D,A,R,J_{\mathrm{true}}\) |
| `conflict_components` | 当前道路重叠组件及 Age/Breakout 状态 |
| `point_search_states` | 每个持久点 ID 的 Tabu 和阈值状态 |
| `adjustment_attempts` | 局部调整事务 |
| `local_priority_blocks` | 五点最高优先块 |
| `round_index` | 当前轮次 |

## 4. 算法流程：初始化

1. 为每条控制折线构造道路掩码。
2. 建立 `occupancy_count`。
3. 计算 \(L,D,A,R,J_{\mathrm{true}}\)。
4. 提取重叠冲突组件。
5. 初始化控制点搜索状态、冲突 Age 和 Breakout 权重。
6. 保存初始合法网络为 best-so-far。

## 5. Effect Score

Effect Score 衡量控制点对附近重叠冲突的影响，只用于决定普通调度顺序，不直接进入最终目标。

控制点对其路径上、沿路径距离不超过 \(\beta_6\) 的冲突组件累积影响；冲突面积越大、距离越近、Age 越高，Effect Score 越高。

移动后应更新受影响区域的冲突和未访问点 Effect Score，普通顺序不是在轮开始时永久固定。

## 6. 每轮调度流程

### 6.1 初始化本轮

1. 保存合法轮开始快照。
2. 把本轮开始时存在的全部可移动点放入 `Unvisited`。
3. 清空本轮局部优先队列和调整日志。
4. 重算 Effect Score。
5. 选择调度模式：
   - 奇数轮：`STRICT_EFFECT`；
   - 偶数轮：`TEN_PERCENT_RANDOM`。

本轮新插入点从下一轮开始参与普通优化。

### 6.2 选择下一个控制点

选择优先级为：

1. 如果存在 `LocalPriorityBlock`，按块内路径顺序处理队首点；
2. 否则在严格轮选择当前 Effect Score 最大的未访问点；
3. 在随机轮，每次普通选择以 0.10 概率从当前 `Unvisited` 均匀随机选一点，否则选最高 Effect 点。

随机抽样结果必须记录并可复现。

## 7. 局部五点视野

当前点 \(C_i\) 的局部视野为：

\[
W_i=\{C_j\mid\max(0,i-2)\leq j\leq\min(M,i+2)\}.
\]

通常包含前两个点、当前点和后两个点。已经在本轮完成调整的局部点形成约束边界，后续点不能为了改善目标而破坏这些已承诺点相关的正式约束。

局部第一个实际调整点可以把直接相关转角上限临时放宽到：

\[
2\beta_\theta.
\]

该放宽只属于本次局部调整事务，不改变最终约束，也不放宽碰撞、\(\beta_{10}\) 或 \(\beta_{12}\)。

## 8. 候选位置生成与动态预过滤

令候选分辨率为 \(\delta_C\)，\(\beta_4\) 是固定的整数轴向半宽。名义候选为：

\[
\mathcal Q_i=\{C_i+(u\delta_C,v\delta_C)\mid
u,v\in[-\beta_4,\beta_4]\cap\mathbb Z\}.
\]

每个轴有 \(2\beta_4+1\) 个位置，二维名义候选最多为 \((2\beta_4+1)^2\)，包含当前位置。

候选掩码不是永久缓存。每次开始优化一个控制点时，必须使用当前控制点坐标、当前相邻关系、当前访问状态和当前其他路径位置重新生成；任何控制点移动、失败恢复、补点或重编号后，旧掩码立即失效。

本次评价先生成 `base_legal_mask`，逐个候选提前排除：

1. 地图边界非法；
2. 移动固定端点；
3. 产生零长度线段；
4. 新线段接触硬障碍；
5. 超过 \(\beta_{12}\)；
6. 破坏 \(\beta_{10}\) 真实转弯间隔；
7. 破坏已经正式提交、且不属于当前开放局部事务的控制点约束。

上述基础非法候选在任何情况下都不能重新启用。然后对 `base_legal_mask` 中的候选重新计算当前转角及其超限量：

1. 若存在满足正式 \(\beta_\theta\) 的候选，建立 `strict_turn_mask`，只允许这些正式合法候选进入目标增量计算；
2. 若不存在正式合法候选，建立 `turn_reduction_mask`，只保留能够严格减小当前局部窗口总转角超限量的候选；
3. 若当前点是开放局部事务的发起点，`turn_reduction_mask` 中的候选仍不得超过临时上限 \(2\beta_\theta\)；
4. 如果没有候选能够严格减小超限量，当前点保持原位。

只有 `strict_turn_mask` 或必要时的 `turn_reduction_mask` 中的候选才计算 \(\Delta L,\Delta D,\Delta A,\Delta R\)。因此实际计算候选数可以小于固定名义邻域，而且同一控制点在不同优化时刻得到的掩码可以不同。

## 9. 局部约束优先的候选选择

候选先按动态掩码和约束，再按搜索目标比较：

1. 与已承诺点相关的永久合法性；
2. 正式转角的总超限量；
3. 最大单点转角超限量；
4. 搜索目标增量；
5. 稳定位置键。

具体规则：

- 只要 `strict_turn_mask` 非空，角度不合法的候选不能因目标更优而胜出。
- 只有 `strict_turn_mask` 为空时，才从 `turn_reduction_mask` 中选择总超限量最小、且最接近约束角度的候选。
- 如果没有候选能严格减小超限量，当前点保持原位，等待发起调整失败恢复。

在最优约束等级内部，再应用 Reactive Tabu 和 Adaptive Threshold：优先选择改善搜索目标的候选；没有改善时，只允许在当前阈值内有限恶化。

## 10. 局部障碍代价和路径排斥增量

### 10.1 障碍代价 \(D\)

对候选位置改变的局部中心线段生成有序栅格经过记录。每次经过栅格 \(c\) 都读取 `obstacle_cost_field[c]` 并累计；同一路径重复经过同一栅格时重复计数。移动增量为新局部段累计值减去旧局部段累计值。

### 10.2 路径排斥代价 \(R\)

优化路径 \(r\) 的控制点时，只评价该控制点局部视野内发生变化的路径几何。路径 \(r\) 不对自身产生排斥；其他路径 \(s\ne r\) 产生排斥场并在栅格上累计：

\[
F_{-r}(c)=\sum_{s\ne r}F_s(c).
\]

例如一个栅格同时包含在三条其他路径的排斥区域中，该栅格排斥值为三条路径贡献之和。候选的排斥增量只比较新旧局部路径在这个累计场中的代价差，其他路径在本次事务中保持不动。

障碍渐变权重和单路径排斥场 \(F_s\) 的具体数值公式分别从《障碍物渐变膨胀》和《排斥半径计算方式》导入；局部增量与全局重算必须调用同一公式实现。

## 11. 移动提交与缓存更新

一次接受移动必须作为一个事务：

1. 保存旧位置和局部五点窗口；
2. 更新当前点和相邻两条线段；
3. 更新道路掩码、占用计数和指标缓存；
4. 更新冲突组件；
5. 重新识别真实转弯和受影响约束；
6. 写入移动日志和 `AdjustmentAttempt`；
7. 更新 Effect Score、Tabu 和阈值状态。

若使用了临时 \(2\beta_\theta\)，必须保存唯一发起点和调整前位置。

## 12. 后续点协同与失败恢复

后续局部点按普通 Effect 顺序或最高优先块顺序承担角度恢复压力。

当局部窗口处理完成：

- 若全部正式约束恢复，事务提交，标记为 `COMMITTED` 或 `REPAIRED_BY_LATER_POINT`。
- 若仍有正式角度违规，只恢复发起控制点到本次调整前的位置，标记为 `FAILED_RESTORED`。
- 失败不建立 Failed-Decision Tabu，未来轮次允许在新的局部上下文中重试。
- 与发起调整无依赖且恢复后仍合法的其他移动可以保留。

## 13. 五点最高优先块

恢复发起点后，完整检查前二、当前、后二点。如果局部仍非法：

1. 创建 `LocalPriorityBlock`；
2. 按路径顺序排列为 `i-2, i-1, i, i+1, i+2`，边界处截断；
3. 该块整体提升到最高优先级；
4. 块处理期间不允许其他高 Effect 点或 10% 随机点插队；
5. 固定点参与合法性判断但不移动；
6. 块内点仍使用相同的候选预过滤和约束优先规则；
7. 块处理后重新检查局部合法性；
8. 重试预算耗尽时，恢复窗口内尚未确认合法的本轮调整，使其回到最近合法状态。

## 14. 轮末处理

1. 关闭所有仍未完成的局部调整事务；不能把临时 \(2\beta_\theta\) 状态带到轮末。
2. 对超过 \(\beta_{12}\) 的线段插入共线控制点。
3. 为新点分配持久 ID；新点下一轮参与优化。
4. 按路径重新编号并重建邻接、线段、累计弧长和调度索引。
5. 重算本轮真实目标。
6. 只有正式约束全部满足时，才与 best-so-far 比较。
7. 更新冲突 Age 和下一轮 Breakout 权重；每个冲突每轮最多增加一次 Age。

## 15. 输出接口

### `ControlOptimizationResult`

| 字段 | 含义 |
|---|---|
| `best_network` | 最好且合法的 `NetworkState` |
| `rounds_completed` | 完成轮数 |
| `stop_reason` | 达到 \(K\) 或其他正常停止原因 |
| `objective_trace` | 每轮合法目标值 |
| `selection_trace` | 调度模式、随机抽样和点选择记录 |
| `adjustment_trace` | 移动、协同修复、失败恢复和最高优先块记录 |

## 16. 基本功能检查

- 固定端点不会移动，所有提交线段无硬碰撞。
- 每次优化控制点前都会按当前网络状态重新生成候选掩码，旧掩码不会跨移动复用。
- 基础非法候选在指标计算前被屏蔽；正式转角合法集合为空时，只启用严格减小超限量的候选。
- \(D\) 按中心线栅格经过记录累计，重复经过重复计数。
- \(R\) 排除被优化路径自身，并能累计其他多条路径在同一栅格的排斥贡献。
- 局部首个调整点不超过 \(2\beta_\theta\)，轮末全部转角不超过 \(\beta_\theta\)。
- 后续点无法修复时只恢复发起点，且不创建失败禁忌。
- 恢复后仍非法时，五点按路径顺序获得最高优先级。
- 奇数轮严格按 Effect；偶数轮使用可复现的 10% 随机选择。
- best-so-far 始终来自完整合法的轮末网络。
