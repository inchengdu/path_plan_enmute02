# 算法阶段 2：地图生成与代价场

## 1. 阶段作用

生成满足面积与形态要求的原始障碍地图，并构造路径搜索和连续优化使用的硬障碍图、距离场与障碍代价场。

如果用户提供外部地图，本阶段可跳过随机形状生成，但仍需完成障碍语义统一、机器人半径膨胀、距离场和障碍代价场构造。

## 2. 输入接口

### `MapStageInput`

| 字段 | 含义 |
|---|---|
| `config` | `NormalizedConfig` 中的地图参数 |
| `map_random_stream` | 地图专用随机流 |
| `external_raw_map` | 可选的外部原始障碍掩码 |

主要配置包括地图边长 \(\eta_1\)、障碍总面积比例 \(\eta_2\)、单障碍面积范围 \([\eta_3,\eta_4]\)、形态约束、放置间距、机器人半径和重试预算。

## 3. 算法流程

### 3.1 确定障碍面积

1. 计算地图面积 \(A_{\mathrm{map}}=\eta_1^2\)。
2. \(\eta_2\) 使用 \([0,1]\) 小数比例语义，计算目标障碍面积：
   \[
   \boxed{A_0=\eta_2A_{\mathrm{map}}}.
   \]
   例如 \(\eta_2=0.10\) 表示 10%，不得再次除以 100。
3. 在允许误差内确定最终总面积和障碍数量。
4. 把总面积分配给多个障碍，保证每个障碍面积位于 \([\eta_3,\eta_4]\)。

### 3.2 生成并放置障碍

对每个障碍：

1. 生成低频平滑随机形状；
2. 调整尺度使栅格面积接近目标；
3. 保证障碍连通、无洞且形态不过度狭长；
4. 按面积从大到小放置；
5. 保证障碍在地图内，不与已有原始障碍重叠，并满足最小分离距离；
6. 单障碍失败时重试当前形状，整体预算耗尽时重启地图。

### 3.3 构造硬障碍

对原始障碍执行机器人半径膨胀：

\[
\mathcal O_{\mathrm{hard}}
=\mathcal O_{\mathrm{raw}}\oplus B(r_{\mathrm{robot}}).
\]

膨胀后不同原始障碍可以合并。

### 3.4 构造距离场与障碍代价场

1. 对硬障碍计算欧氏距离场。
2. 根据原始障碍物及其渐变膨胀边界计算 `obstacle_cost_field`。
3. 在距离障碍影响范围不超过 \(\beta_1\) 的区域内保存非负渐变权重。
4. 距离超过 \(\beta_1\) 后，渐变膨胀部分的权重为 0。
5. 权重在接近障碍边界时不能降低。

具体障碍物权重、渐变边界和叠加公式以《障碍物渐变膨胀》为准。合法路径的障碍代价不在本阶段汇总；本阶段只生成后续按中心线栅格经过记录查询的代价场。

## 4. 输出接口

### `GridMap`

| 字段 | 含义 |
|---|---|
| `size` | 地图边长 |
| `raw_obstacle_mask` | 原始物理障碍布尔图 |
| `obstacle_id_map` | 原始障碍 ID 图 |
| `hard_obstacle_mask` | 机器人膨胀后的碰撞障碍图 |
| `hard_distance_field` | 到硬障碍的欧氏距离 |
| `obstacle_cost_field` | 原始障碍及渐变膨胀边界的栅格权重场 |
| `obstacle_records` | 每个原始障碍的面积、位置和形态信息 |

### `MapStageReport`

包含最终面积、障碍数量、重试次数和停止状态。

## 5. 基本功能检查

- 原始障碍均在地图内且互不重叠。
- 障碍总面积与单障碍面积满足配置范围。
- 硬障碍图确实包含机器人半径膨胀结果。
- \(\eta_2=0.10\) 时目标障碍面积等于地图面积的 10%。
- 距离超过 \(\beta_1\) 后渐变膨胀部分的权重为 0。
- 相同配置和种子生成相同地图。
